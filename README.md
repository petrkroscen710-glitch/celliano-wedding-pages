# Celliano public wedding embed

Minimal public-only export for the Celliano wedding section.

Files intended for the public Pages repository:
- `index.html`
- `embed.js`
- `svatby/index.html`
- `.nojekyll`

The wedding markup is based on the restored stable production design. The public page is marked `noindex,nofollow` and is intended to be embedded into celliano.cz.
